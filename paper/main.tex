\begin{abstract}
This document presents a comprehensive system description of a custom-engineered, multimodal data collection platform designed for PhD-level Velocity-Based Training (VBT) research.
The system integrates a TDK InvenSense ICM-42688-P inertial measurement unit, sampled at a deterministic \SI{1}{\kilo\hertz} via interrupt-driven SPI on an ESP32 microcontroller, with an Intel RealSense D455 stereo depth camera operating at \SI{90}{fps}.
Hardware-level synchronisation is achieved through a discrete NPN-transistor level-shifting circuit that converts the D455's \SI{1.8}{\volt} CMOS \texttt{FRAME\_SYNC} output to \SI{3.3}{\volt} logic, driving both the ESP32 GPIO and the IMU's internal FSYNC tagging engine simultaneously.
Wireless data telemetry from the barbell-mounted sensor node uses ESP-NOW with 8-sample batching, yielding a \SI{125}{\hertz} radio duty cycle well within the protocol's capacity.
On the host side, a C++17 application built with CMake manages real-time data ingestion, marker tracking, and session orchestration, while a Python-based golden-model pipeline implements attitude estimation (Madgwick, MEKF, and VQF), a 15-state Error-State Kalman Filter with lifting-specific Zero-Velocity Updates, and camera-oracle fusion strategies for sub-\SI{50}{\milli\metre} positional accuracy.
All sessions are persisted in a schema-versioned (v4) JSON format encompassing over 120 metadata fields spanning athlete anthropometrics, training periodisation, loading provenance, and subjective quality assessments, with optional BIDS-compliant directory layouts for multi-subject archiving.
\end{abstract}
